AI APIを、ここから。

UserLocalのチャットBotをバックエンド経由で呼び出し、 発行したAPIキーを使って自分のアプリから利用できる 開発者向けAPIポータルです。

管理者ログイン

サーバー環境変数 ADMIN_PASSWORD に設定した パスワードを入力してください。

APIキーを発行

用途ごとにキーを作成できます。 発行時に表示されるキー本体は、 その場で必ずコピーしてください。

発行済みキー

漏えいしたキーはすぐに無効化してください。

チャットテスト

管理者ログイン後、UserLocalのBotに接続して 動作確認できます。

APIの使い方

発行したAPIキーをBearerトークンとして送信します。 レスポンス形式はOpenAI Chat Completionsに近いJSONです。

POST /v1/chat/completions
curl -X POST "https://YOUR-DOMAIN/v1/chat/completions" \ -H "Authorization: Bearer YOUR_API_KEY" \ -H "Content-Type: application/json" \ -d '{ "messages": [ {"role": "user", "content": "こんにちは"} ] }'

JavaScriptから呼び出す

const response = await fetch( "https://YOUR-DOMAIN/v1/chat/completions", { method: "POST", headers: { "Authorization": "Bearer YOUR_API_KEY", "Content-Type": "application/json" }, body: JSON.stringify({ messages: [ { role: "user", content: "こんにちは" } ] }) } ); const data = await response.json(); console.log(data.choices[0].message.content);
APIキーを公開Webサイトのフロントエンドに埋め込まないでください。 ブラウザから見えるキーは第三者にコピーされる可能性があります。 公開アプリでは必ず自分のバックエンドからこのAPIを呼び出してください。

このAPIはUserLocalの外部サービスを中継します。 利用可否・回数制限・利用規約はUserLocal側の条件に従います。 応答内容やモデル名をこのアプリが独自に保証するものではありません。
